# Smart Product Explorer

## Description

This is a data-driven Single Page Application (SPA) built using Vue 3, TypeScript, and Tailwind CSS. The application fetches product data from the DummyJSON API and allows users to search, filter, view product details, and manage a shopping cart and wishlist.

## Features

* Fetch products from DummyJSON API
* Search products
* Filter by category
* Product detail modal
* Shopping cart with persistence (localStorage)
* Wishlist feature
* Dark mode

## Installation & Setup

### Step 1: Install dependencies

npm install

### Step 2: Run the development server

npm run dev

### Step 3: Open in browser

Open the URL shown in the terminal (usually http://localhost:5173/)
